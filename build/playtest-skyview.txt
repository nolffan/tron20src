# playtest-skyview.txt -- the engine's retail-bug fixes EN-81, EN-82 and
# EN-83 (docs/MODERN.md), in M01-02 (its sky is seen from the start), on
# the modern build (the legacy build has no console). Through the
# developer console (EN-70): the I/O node camera (the inset view of an
# I/O node, LAYOUT.TXT IOCameraRect, at the middle top of the screen) is
# put at named objects near the start with "iocam on <object> <object>",
# the player's command that the levels use for their I/O nodes (with
# "cmd msg player"; the quotes are typed as keys, since "type" can drop
# the Shift of a character). The first inset is shot with DrawSky 1 and
# 0: its sky is the area that goes black. Then HighPriority set (EN-81:
# "Setting process to high priority" once, not each frame) and cleared
# ("Setting process to normal priority" once; retail never puts it back),
# and the variable "version" (EN-83: "unknown", not
# 4294967295.4294967295; wine.log has "LithTech build unknown
# initialized"). Run it at a widescreen resolution:
#   make test TEST_GAME=out/tron20-modern-release \
#     TEST_SCRIPT=build/playtest-skyview.txt TEST_RES=1920x1080
# world: Worlds\RetailSinglePlayer\M01-02
